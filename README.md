SuperStore Sales Dashboard - Power BI

Project Overview

This project was developed as part of the Data Analyst Internship Task 4: Dashboard Design. The objective was to create an interactive Power BI dashboard that helps business stakeholders analyze sales performance, profitability, customer behavior, and market trends.

The dashboard provides meaningful insights through KPIs, charts, filters, and interactive visualizations to support data-driven decision-making.

---

Tools Used

* Power BI Desktop
* Microsoft Excel / CSV Dataset
* GitHub

---

Dataset Information

The project uses the SuperStore Orders dataset, which contains sales transaction records from 2011 to 2014.

Dataset Features

* Order Details
* Customer Information
* Product Categories
* Regional Sales Data
* Market Information
* Sales and Profit Metrics

Key Columns

* Order ID
* Order Date
* Customer Name
* Category
* Sub-Category
* Region
* Market
* Sales
* Profit
* Quantity
* Discount

Key Insights

* Total Sales reached approximately 7.84 Million.
* Total Profit exceeded 1.47 Million.
* Technology category generated the highest profit.
* Central region recorded the highest sales.
* Sales showed continuous growth from 2011 to 2014.

---
Business Recommendations

* Focus on high-performing product categories.
* Expand business operations in top-performing regions.
* Improve sales strategies in low-performing regions.
* Monitor product profitability regularly.
* Use dashboard insights to support business decisions.
